# ai-docs

集中保存 Omni 产品线的设计、计划与验证文档。
不承载业务运行时文件，也不替代代码内的接口和架构说明。
每个子目录负责维护自己的 `.folder.md` 索引。

## 文件与目录

- `plans/`：已经确认的产品设计与后续实施计划。
