# integration

存放需要跨越服务、仓储或 HTTP 边界的后端集成测试。
`integration` 标签使用隔离 PostgreSQL，`e2e` 标签面向可配置的运行中网关。
默认单元测试不会自动执行本目录的带标签测试。

## 文件

- `e2e_gateway_test.go`：验证 Claude 与 Gemini 兼容网关的请求、流式响应和错误路径。
- `e2e_helpers_test.go`：提供 E2E Mock 模式、凭证检查和通用辅助函数。
- `e2e_user_flow_test.go`：验证注册、登录、创建 Key、调用网关和查询用量的用户链路。
- `user_activation_flow_test.go`：使用隔离 PostgreSQL 验证官网新用户体验、召回与付费未成功支持链路。
