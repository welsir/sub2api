# Qwen3Guard Moderation Adapter Tests

Contract and runtime-path tests for the standalone text moderation adapter.

- `classification.test.ts`: TypeScript parser and deterministic mapping contract.
- `minimax.test.ts`: Strict MiniMax decisions, injection and harmless-outer-task/history-wrapping isolation, canonical controlled marker grammar, policy revision, M2/M3 thinking controls, tier selection, and prompt-separation contract.
- `minimaxBackend.test.ts`: Exact two-message MiniMax request/tier, sensitive/uncertain blocking, readiness, and provider-error contract.
- `config.test.ts`: Environment, URL containment, credential-boundary, and deadline contract.
- `fixtures.ts`: Stable fake Qwen structured-output cases.
- `adapterContract.test.ts`: Qwen/MiniMax HTTP plus classifier-revision handshake, direct-image fail-closed, raw-target, gzip, bounds, health, and shutdown contract.
- `distRuntime.test.ts`: Build topology plus emitted MiniMax high-speed and quota-error regression contract.
- `runtime.test.js`: Emitted `dist/` gzip/server smoke and structured listen-error contract.
