# Qwen3Guard Moderation Adapter Tests

Contract and runtime-path tests for the standalone text moderation adapter.

- `classification.test.ts`: TypeScript parser and deterministic mapping contract.
- `classification.test.js`: Checked-in JavaScript runtime mapping smoke contract.
- `minimax.test.ts`: Strict MiniMax decisions, M2/M3 thinking controls, tier selection, and prompt-separation contract.
- `minimaxBackend.test.ts`: MiniMax request/tier, sensitive signal, readiness, and provider-error contract.
- `config.test.ts`: Environment, URL containment, credential-boundary, and deadline contract.
- `fixtures.ts` / `fixtures.js`: Stable fake Qwen structured-output cases.
- `adapterContract.test.ts`: Qwen/MiniMax HTTP, raw-target, gzip, bounds, health, and shutdown contract.
- `runtime.test.js`: Checked-in JavaScript gzip/server smoke and structured listen-error contract.
