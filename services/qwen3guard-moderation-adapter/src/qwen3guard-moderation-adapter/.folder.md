# Qwen3Guard Moderation Adapter

Independent OpenAI-shaped text moderation service in front of Qwen or MiniMax Chat Completions.

- `classification.ts` / `classification.js`: Versioned parser, policy scores, and redacted mapping metadata.
- `minimax.ts` / `minimax.js`: Strict MiniMax request prompt, final-JSON parser, and sensitive-result mapping.
- `config.ts` / `config.js`: Strict provider selection, contained-path URL policy, and bounded deadlines.
- `backend.ts` / `backend.js`: Origin-contained, byte-bounded Qwen/MiniMax clients with typed failures.
- `metrics.ts` / `metrics.js`: In-memory counters, latency totals, and scheduler gauges.
- `server.ts` / `server.js`: Raw-target-safe parsing, bounded gzip decoding, body deadlines, moderation, health, metrics, and shutdown.
- `main.ts` / `main.js`: Structured listen lifecycle and hard-deadline shutdown entrypoint.
