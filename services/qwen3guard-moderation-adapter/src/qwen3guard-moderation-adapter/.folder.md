# Qwen3Guard Moderation Adapter

Single-source TypeScript OpenAI-shaped moderation service compiled for Qwen or MiniMax Chat Completions.

- `classification.ts`: Versioned parser, policy scores, and redacted mapping metadata.
- `minimax.ts`: Versioned deterministic MiniMax prompt with injection and harmless-outer-task/history-wrapping resistance, a canonical controlled attachment-marker grammar, zero-temperature model controls, final-JSON parser, and sensitive/uncertain fail-closed mappings.
- `config.ts`: Strict provider/tier selection, contained-path URL policy, and bounded deadlines.
- `backend.ts`: Origin-contained, byte-bounded clients with typed transport failures and MiniMax classifier uncertainty blocking.
- `metrics.ts`: In-memory counters, latency totals, and scheduler gauges.
- `server.ts`: Raw-target-safe parsing, Unicode code-point input bounds, bounded gzip decoding, classifier-revision readiness/response metadata, deterministic direct-image fail-closed policy, metrics, and shutdown.
- `main.ts`: Structured listen lifecycle and hard-deadline shutdown entrypoint compiled into `dist/`.
