# Qwen3Guard Moderation Adapter

Independent OpenAI-shaped text moderation service in front of a local Qwen Chat Completions backend.

- `classification.ts` / `classification.js`: Versioned parser, policy scores, and redacted mapping metadata.
- `config.ts` / `config.js`: Strict contained-path URL policy and bounded runtime deadlines.
- `backend.ts` / `backend.js`: Origin-contained, byte-bounded Qwen client with typed cancellation.
- `metrics.ts` / `metrics.js`: In-memory counters, latency totals, and scheduler gauges.
- `server.ts` / `server.js`: Raw-target-safe parsing, body deadlines, moderation, health, metrics, and shutdown.
- `main.ts` / `main.js`: Structured listen lifecycle and hard-deadline shutdown entrypoint.
